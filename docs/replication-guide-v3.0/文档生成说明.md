# 文档生成和验证

Markdown是指南正文的来源，build_guide.py用python-docx生成Word。字体为macOS自带Heiti SC，标题无装饰横线，表格使用浅色表头、重复表头和自适应行高。

使用Codex的documents技能和其工作区依赖运行build_guide.py，再用技能随附render_docx.py执行DOCX转PDF和逐页PNG检查。其他系统需安装可显示中文的字体并明确配置，不可交付缺字版本。该字体仅用于项目书，不能作为原版游戏字库替代品。

本轮先修正缺失的中文字体与默认标题装饰，最终渲染45页。逐页检查布局并核对文本边界，没有发现超出页边距或页脚冲突；摘要和页数见版式验证报告.json。临时PNG与接触表未加入交付包。
