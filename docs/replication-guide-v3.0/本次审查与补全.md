# v3.0审查修复结果

本版修复前次项目书审查发现的工具和流程缺陷，保留38章与6个附录，并提供更新后的Word、PDF、Markdown和完整交付包。当前完成的是施工规范和工具，原版事实、游戏开发和真实站点仍待落实。

| 原审查问题 | 本版处理 | 验证与剩余边界 |
| --- | --- | --- |
| 线上报告旧期望和旧实测能互相对上 | 报告头、实际网页观察、候选、dist和外部CI身份同时核对 | 同时改旧版本、换域名、改路径的反例均被拒绝 |
| 案例不存在、实施任务被删仍放行 | 新增cases与冻结scope，逐案例断言，清单与外部摘要绑定 | 删分母、虚构案例、改阶段、缺断言均被拒绝；原版范围穷尽仍需独立复核 |
| 首发顺序矛盾与OPS-PREP循环前提 | 独立跨job传递验证先执行，OPS-PREP只依赖ENG；先构建和dist测试再门禁 | 台账、章节和工作流使用同一依赖顺序；未实际运行GitHub游戏CI |
| 回滚只有文字和短期附件 | 完整归档与SHA256保存在持久Release；恢复核对tag、版本和全部文件，提供自动/手动模板 | 本地归档真打包真恢复；GitHub边界用模拟响应，未部署；首次无旧版不能假称可回滚 |
| 原版事实未齐 | 第31章列出逐项采集规格、场景字段、规则案例和解除条件，登记本地旧资料候选 | 缺少原件或独立验证的字段保持未知；没有填造原版数值、画布和公式 |

本轮80项工具检查通过：62项交付/像素/产物/归档反例，11项模拟GitHub接口与真实本地恢复，7项工作流静态及本地传递脚本检查。报告位于AI交付包。该计数不代表游戏案例、原版对照或真实线上验收数量。

## 接续使用

按阅读顺序进入指南和START_HERE。v3采用project schemaVersion=2，新增scope.json和cases.json；reports.json改为id/path/sha256，链接真实原始运行报告。旧v2报告须保留历史并按真实执行迁移，不能直接复制passed。

Word、PDF和Markdown为同一指南来源；工作流保留.example，尚未启用。zip含指南、台账、工具、模板、复现脚本与本轮实际工具报告。完整还原或上线仍必须由真实原版资料和游戏运行证明。
