# v2.1交付内容与使用顺序

1. 自己阅读指南第19章：明确完全复刻目标和不能接受的替代行为。
2. 将整个交付包提供给能读写文件、执行代码和运行浏览器的AI。
3. 把《给AI的第一句话.txt》作为任务要求发送，让它先读START_HERE，再核实仓库并执行DOC-001。
4. 每次换AI保留实际源码、参考资料、台账、报告及PROGRESS，要求先核实并继续，不重新自由设计。

指南提供Word可编辑版、PDF阅读版、Markdown源码版；正文38章、附录6份。AI交付包含24个任务组、7个初始未知项、JSON／CSV台账、执行约束、交接表、资料检查器和零容差像素比较器。

工具自测报告记录人工小图与故意错误台账的检查结果，只验证辅助工具，不表示游戏已开发或原版还原通过。原始上传ROM不包含在本包内。

实际原版截图、录像、字库与规则证据仍需补齐。更详细的文档和检查工具能防止擅自发挥，但不能替代原版事实；没有证据时必须保持待确认，不允许把猜测当完全复刻。
